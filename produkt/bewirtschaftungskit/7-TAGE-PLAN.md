# 7-Tage-MVP: Zahlungsbereitschaft testen

Ziel dieser Woche ist NICHT "Produkt perfektionieren", sondern: einen ersten
zahlenden Kunden finden bzw. eindeutige Kaufsignale messen – mit maximal
2 Std./Tag.

## Tag 1 — Vorbereitung
- [ ] Angebot, Preis, Zielgruppe final festlegen (siehe PREISSTRUKTUR.md)
- [ ] Copy der Landingpage gegenlesen, an eigenen Ton anpassen
- [ ] Zielgruppenliste starten: 20–30 Kontakte sammeln (siehe
      marketing/Cold-Outreach-E-Mails.md, Abschnitt Zielgruppen-Quellen)

## Tag 2 — Produkt fertigstellen
- [ ] `vorlagen/Leerstandsliste-und-Fristenplan-Vorlage.xlsx` in Excel/Google
      Sheets öffnen, einmal komplett durchklicken, eigene Beispielzahlen testen
- [ ] Checkliste (`Checkliste-Mieterwechsel.md`) an eigenen Prozess anpassen,
      als PDF exportieren
- [ ] Alle drei Dateien + Prompt-Bibliothek in einen ZIP-Ordner packen

## Tag 3 — Online stellen
- [ ] Payhip- oder Lemonsqueezy-Konto erstellen, Produkt anlegen, ZIP hochladen
- [ ] Checkout-Link in `landingpage/index.html` einsetzen (Platzhalter ersetzen)
- [ ] Landingpage hosten (z. B. GitHub Pages, Carrd, oder direkt als Payhip-
      Produktseite mit dem Text aus der Landingpage)

## Tag 4 — Erste Kontakte
- [ ] Zielgruppenliste auf 30–40 Kontakte auffüllen
- [ ] Erstkontakt-Mail/-Nachricht an 15–20 Kontakte senden (E-Mail 1 / LinkedIn-
      Nachricht aus marketing/Cold-Outreach-E-Mails.md)

## Tag 5 — Testen & anpassen
- [ ] Reaktionen sichten, Einwände notieren
- [ ] Bei Unklarheiten: Copy/Preis/Zielgruppen-Beschreibung nachschärfen
- [ ] 1–2 relevante Online-Gruppen identifizieren (LinkedIn-Immobiliengruppen
      Schweiz, SVIT-Foren) für einen kurzen, nicht-werblichen Hinweis-Post

## Tag 6 — Zweite Runde
- [ ] Follow-up-Mail (E-Mail 2) an alle ohne Antwort senden
- [ ] Restliche 15–20 Kontakte aus der Liste erstkontaktieren
- [ ] Optional: Hinweis-Post in 1–2 Gruppen veröffentlichen

## Tag 7 — Entscheidung
- [ ] Zahlen auswerten: Kontaktierte, Antwortquote, Kaufabsichten, Verkäufe
- [ ] Entscheidungsregel:
  - ≥ 1 zahlender Kunde ODER ≥ 3 klare Kaufsignale → weiter ausbauen
    (mehr Outreach, Preis/Positionierung leicht optimieren)
  - 0 Resonanz trotz ≥ 30 qualifizierten Kontakten → Positionierung/Zielgruppe
    grundlegend hinterfragen oder zu einem der anderen 4 Modelle wechseln
    (siehe Hauptanalyse)

## Messgrössen (in marketing/Cold-Outreach-E-Mails.md tracken)
- Anzahl kontaktierte Personen
- Antwortquote (%)
- Anzahl "Ja, sende Vorschau" / Landingpage-Klicks
- Anzahl tatsächliche Käufe
