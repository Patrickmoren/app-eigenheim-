# Checkliste Mieterwechsel

Druckbare Checkliste für den Ablauf von der Kündigung bis zur Neuvermietung.
Generische Vorlage – vor Verwendung an den eigenen Mietvertrag/Prozess anpassen.

## 1. Kündigungseingang

- [ ] Kündigungsdatum und -form (Brief, Formular) im Fristenrechner erfassen
- [ ] Kündigungsfrist gemäss Mietvertrag prüfen
- [ ] Kündigung schriftlich bestätigen (Eingangsbestätigung an Mieter)
- [ ] Rückgabetermin berechnen und im Kalender eintragen
- [ ] Objekt in der Leerstandsliste erfassen

## 2. Vorbereitung Vermarktung (ab empfohlenem Startdatum)

- [ ] Fotos/Grundriss aktuell und vorhanden?
- [ ] Inserat erstellen (siehe KI-Prompt-Bibliothek, Prompt 1–2)
- [ ] Mietzins prüfen: unverändert, anpassen, oder Marktvergleich?
- [ ] Besichtigungstermine planen

## 3. Besichtigung & Auswahl

- [ ] Interessenten-Anfragen sammeln (eine Liste, ein Ort)
- [ ] Besichtigungen durchführen
- [ ] Bonitätsprüfung / Unterlagen der Wunschmieter einholen
- [ ] Mietvertrag vorbereiten

## 4. Vor der Rückgabe

- [ ] Abnahmetermin mit bisherigem Mieter vereinbaren
- [ ] Abnahmeprotokoll vorbereiten
- [ ] Zählerstände (Strom/Wasser, falls separat) einplanen
- [ ] Schlüsselübergabe organisieren

## 5. Rückgabe / Abnahme

- [ ] Wohnungsabnahme durchführen, Mängel protokollieren
- [ ] Abnahmeprotokoll unterschreiben lassen (beide Parteien)
- [ ] Kaution/Rückzahlung klären
- [ ] Schlüssel zählen und quittieren

## 6. Übergabe an neue Mieter

- [ ] Übergabeprotokoll vorbereiten
- [ ] Zählerstände bei Übergabe erfassen
- [ ] Mietvertrag unterschrieben, Kopie an Mieter
- [ ] Leerstandsliste aktualisieren: Status "vermietet", Enddatum eintragen

## 7. Abschluss

- [ ] Leerstandskosten für internen Rapport/Eigentümer-Update dokumentieren
- [ ] Fall in der Leerstandsliste archivieren
