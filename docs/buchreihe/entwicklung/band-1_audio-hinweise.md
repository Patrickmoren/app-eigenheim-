# Band 1 – Audio-Hinweise *(intern, zugleich Regie für das Hörbuch)*

> Kapitelnummern ab K11 folgen der Architektur vom 29.09.2026 (Band 1 = 35 Kapitel, siehe `band-1_produktionsplan.md` §C.2).

Prinzip: Jedes Motiv durchläuft **Atmosphäre → Hinweis → Beweis**. Im Hörbuch ist die Lösung akustisch da, bevor sie im Text verstanden wird.

**Hörbuch-Grundsatz:** Kein Geräusch wird eingefügt, das im Text keine Quelle hat. Die Tonband-Transkripte werden als Tondokumente produziert (gleiche Sprecherin für Kathi und Leni mit minimalen Unterschieden, Pfiff als einziges Unterscheidungsmerkmal).
