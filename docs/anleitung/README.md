# Bedienungsanleitung

`Bedienungsanleitung-Leerstandsmanager.docx` erklärt die Bedienung des Prototyps – ergänzend zur
fachlichen `docs/prozesse/Prozessbeschreibung-Mieterwechsel.docx`, die die Abläufe beschreibt.

| Dokument | Frage |
|---|---|
| Prozessbeschreibung | Was passiert fachlich, in welcher Reihenfolge, mit welchen Fristen? |
| Bedienungsanleitung | Wie erledige ich das in der Anwendung? |

Die Bildschirmabbildungen unter `bilder/` werden aus dem Prototyp erzeugt; das Aufnahmeskript
steht in `docs/anleitung/screenshots.js`. Bei Änderungen am Prototyp erst die Bilder neu
aufnehmen, dann `node build.js` ausführen.
