## Wie dieses Register gepflegt wird

- Nach **jeweils 5 geführten Interviews** (Schritt 9): jede Zeile mit neuer Evidenz aktualisieren, Status ggf. ändern.
- Eine Hypothese wird nur dann **GESTÜTZT**, wenn mindestens 3 unabhängige EVIDENCE-Punkte (nicht blosse Meinungsäusserungen) dafürsprechen.
- Eine Hypothese wird **WIDERLEGT**, sobald mehrheitlich konkrete Gegenevidenz vorliegt — sie wird dann nicht gelöscht, sondern mit Begründung stehen gelassen (Nachvollziehbarkeit).
- Neue Hypothesen (aus Interviews entstehend) werden fortlaufend mit `H14`, `H15`, … ergänzt.
