# 05 · Umsetzung: vom heutigen Tag bis zum ersten Mandat

**1. Januar 2027** aus, weil das zu einer Kündigung per 30. September 2026 bei drei Monaten

## Technik: Cockpit v1 (bis März 2027)

| Baustein | Umfang v1 | Später |
|---|---|---|
| Posteingang | E-Mail, Webformular; Klassifikation, Zuordnung Objekt/Mieter, Antwortvorschlag | WhatsApp (v1.5), Telefon (v2), Brief-Scan |
| Regeln | welche Antworten automatisch gehen dürfen; alles andere Freigabe | Handwerker-Dispatch bis CHF 500 |
| Fristenwächter | Kündigungen, Abnahmen, Übergaben, Schlussabrechnungen, Mietzinsanpassungen | Garantiefristen, Wartungsverträge |
| Eigentümerportal | Mieterspiegel, offene Fälle, Dokumente (nur lesen) | Freigaben, Fragen in normaler Sprache |
| Protokoll | jede automatische Aktion mit Grundlage | Auswertungen für Qualität |
| Anbindung ERP | Import Stammdaten per Export/Schnittstelle | Zweiweg-Synchronisation |

**Grundsätze:** Hosting in der Schweiz; KI-Anbieter nur mit vertraglichem Ausschluss der
Trainingsnutzung und kurzer Datenhaltung; keine Kundendaten in Tests; Rollen und Rechte je Mitarbeitende/r.

**Wichtig:** Das Cockpit wird neu geschrieben. Der Leerstandsmanager-Prototyp in diesem Repository
wird **nicht** übernommen, solange nicht schriftlich geklärt ist, dass er nicht dem bisherigen
Arbeitgeber gehört (OR Art. 332).
